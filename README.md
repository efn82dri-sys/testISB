# سایت سه‌بعدی ISB (گروه ساختمانی بنای پایدار ایران زمین)

این پروژه همان سایت قبلی است، فقط از یک فایل ۲٫۶ مگابایتی به چند فایل مرتب تقسیم شده است.
ظاهر، حرکت دوربین، مکث روی نمای ایزومتریک، زوم و هم‌گامی دستیار با دوربین تغییری نکرده‌اند.
سایت بدون بک‌اند است و مستقیم روی GitHub Pages اجرا می‌شود.

## ساختار پوشه‌ها

```
site/
├─ index.html          اسکلت صفحه و لینک به فایل‌ها (GoatCounter هم اینجاست)
├─ validate.py         بررسی‌کنندهٔ فایل‌های داده
├─ data/               همهٔ متن‌ها و اطلاعات (فقط اینجا را ادیت کنید)
│   ├─ fa.json         متن‌های فارسی صفحه‌ها (درباره، تماس، منو، ...)
│   ├─ en.json         همان متن‌ها به انگلیسی (باید هم‌ساختار fa.json باشد)
│   ├─ projects.json   پروژه‌ها
│   ├─ services.json   خدمات و دوره‌های آموزشی
│   ├─ team.json       اعضای تیم و دفاتر همکار
│   ├─ chapters.json   شش ایستگاه «مسیر پایداری»
│   ├─ town.json       هفت بخش شهرک و خلاصه‌های «پایداری در عمل»
│   ├─ guide.json      متن‌های دستیار ISB و برچسب‌های HUD
│   └─ images.json     فهرست تصاویری که سایت می‌شناسد
├─ css/
│   ├─ fonts.css       تعریف فونت «کلمه»
│   ├─ base.css        رنگ‌ها، تایپوگرافی، کارت‌ها، صفحه‌های داخلی
│   ├─ layout.css      هدر شیشه‌ای، HUD، نوار پیشرفت، موبایل
│   └─ mascot.css      ظاهر دستیار و فرم تیکت
├─ js/
│   ├─ main.js         شروع: داده‌ها را می‌خواند و بقیهٔ فایل‌ها را به ترتیب لود می‌کند
│   ├─ i18n.js         زبان فارسی/انگلیسی
│   ├─ ui.js           منوها، صفحه‌های داخلی، مودال، HUD
│   ├─ scene.js        صحنهٔ سه‌بعدی (ساختمان‌ها، جاده، درخت، ماشین)
│   ├─ camera.js       دوربین و اسکرول
│   ├─ mascot.js       کاراکتر دستیار و فرم تیکت
│   └─ guide.js        توضیح دستیار برای هر بخش هنگام اسکرول
└─ assets/
    ├─ fonts/          چهار وزن فونت
    └─ images/         تصاویر پروژه‌ها، تیم، گواهی‌ها و دستیار
```

## اجرای محلی (تست روی کامپیوتر)

سایت داده‌ها را با fetch می‌خواند، پس با دوبار کلیک روی index.html کار نمی‌کند.
باید یک سرور محلی بالا بیاورید. داخل پوشهٔ site بنویسید:

```
python -m http.server 8000
```

بعد این آدرس را در مرورگر باز کنید:

```
http://localhost:8000
```

بعد از هر ادیت، صفحه را با Ctrl+Shift+R رفرش کنید تا کش مرورگر پاک شود.

## ادیت متن‌ها

هر متن فارسی یک نسخهٔ انگلیسی دارد. هر دو را با هم عوض کنید.

مثال: عنوان یک پروژه در projects.json:

```
"title": { "fa": "مجتمع مسکونی مهرگان", "en": "Mehregan Residential Complex" }
```

- متن‌های عمومی صفحه‌ها (درباره ما، تماس، منو، فوتر): fa.json و en.json
- پروژه‌ها: projects.json
- خدمات و دوره‌های آموزشی: services.json
- تیم: team.json
- شش ایستگاه مسیر پایداری: chapters.json
- نام هفت بخش شهرک: town.json (بخش sections)
- پیام‌های دستیار هنگام اسکرول: guide.json (بخش guide)
- متن فرم تیکت دستیار: guide.json (بخش assistantTexts)

نکته: داخل متن‌ها از علامت " استفاده نکنید، چون JSON خراب می‌شود. به‌جایش از « » استفاده کنید.

## اضافه کردن پروژه جدید

۱. عکس کاور را داخل assets/images/projects/نام-پروژه/ بگذارید (مثلاً cover.jpg).

۲. مسیر عکس را به images.json اضافه کنید:

```
"/projects/my-project/cover.jpg"
```

۳. یک آیتم شبیه آیتم‌های قبلی به projects.json اضافه کنید (slug باید یکتا باشد و coverImage همان مسیر عکس).

۴. اجرا کنید و خطاها را ببینید:

```
python validate.py
```

## اعتبارسنجی داده‌ها

```
python validate.py
```

این فایل بررسی می‌کند:
- JSONها خراب نباشند
- fa.json و en.json کلید به کلید برابر باشند
- هر متن دوزبانه هر دو زبان را داشته باشد
- همهٔ عکس‌های اشاره‌شده روی دیسک وجود داشته باشند
- تعدادهایی که سایت به آن‌ها وابسته است درست باشند (۶ فصل، ۷ بخش شهرک، ...)

قبل از هر آپلود به GitHub یک بار اجرایش کنید.

## استقرار روی GitHub Pages

۱. یک مخزن (repository) بسازید.

۲. محتوای داخل پوشهٔ site را (نه خود پوشه را) در ریشهٔ مخزن آپلود کنید. فایل index.html باید در ریشه باشد. فایل .nojekyll هم باید کنارش باشد.

۳. در مخزن: Settings ← Pages ← Source را روی Deploy from a branch بگذارید، شاخه main و پوشه / (root) را انتخاب کنید.

۴. بعد از یکی دو دقیقه سایت در این آدرس بالا می‌آید:

```
https://USERNAME.github.io/REPO/
```

اگر دامنهٔ شخصی دارید، در همان صفحهٔ Pages وارد کنید.

## آمار بازدید (GoatCounter)

در انتهای index.html عبارت YOUR_CODE را با کد سایت خودتان از goatcounter.com عوض کنید:

```
data-goatcounter="https://YOUR_CODE.goatcounter.com/count"
```

## تنظیمات دستیار و تیکت

بالای فایل js/mascot.js یک بخش تنظیمات (CFG) هست:

```
endpoint:''   آدرس سرویس دریافت تیکت (POST، JSON)
email:''      ایمیل برای ارسال نسخهٔ تیکت
guide:true    توضیح دادن کاراکتر هنگام اسکرول (false = خاموش)
tipDwell:550  مدت توقف روی هر بخش تا کاراکتر شروع به صحبت کند (میلی‌ثانیه)
```

## چیزهایی که نباید دست بخورند

- نسخهٔ three.js در index.html باید 0.150.1 بماند. ظاهر صحنه به رفتار همین نسخه وابسته است.
- ترتیب لود فایل‌ها در js/main.js مهم است: i18n، ui، scene، camera، mascot، guide.
- ترتیب فایل‌های css در index.html مهم است: fonts، base، layout، mascot.
- ثابت‌های دوربین در js/camera.js هستند: نمای کامل با key(0)، ضریب نرم‌سازی اسکرول 5.5 و ضریب دنبال کردن دوربین 9.
- در js/guide.js تابع gPos() باید با منطق دوربین در camera.js یکی بماند تا دستیار با دوربین هم‌گام باشد.

## اگر سایت خالی لود شد

- پیام «سایت لود نشد»: فایل را با file:// باز کرده‌اید؛ از python -m http.server استفاده کنید.
- بعد از ادیت داده، سایت لود نمی‌شود: احتمالاً JSON خراب است. python validate.py را اجرا کنید یا کنسول مرورگر (F12) را ببینید.
- روی GitHub Pages عکسی نمی‌آید: حروف بزرگ و کوچک نام فایل‌ها مهم است (Cover.jpg با cover.jpg فرق دارد).
